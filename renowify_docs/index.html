Renowify : Votre allié pour un web plus accessible

Outil d'aide à la vérification de l'accessibilité des sites web en suivant le référentiel RAWeb

Présentation

Renowify est une extension de navigateur pensée pour les rédacteurs, développeurs, designers et responsables qualité qui souhaitent rendre leurs sites web plus inclusifs et conformes aux standards d’accessibilité numérique. Facile à utiliser et puissante, elle vous permet d’identifier rapidement les obstacles à l’accessibilité et de les corriger efficacement.

Initialement conçue pour répondre aux exigences du référentiel RAWeb, Renowify s’est transformée en un véritable couteau suisse de l’audit d’accessibilité. Elle combine des tests automatisés rigoureux avec des outils d’analyse manuelle pour vous offrir une vision complète de l’état d’accessibilité de vos pages.

Fonctionnalités principales

  • Analyse automatique : En un clic, Renowify exécute plus d’une centaine de tests unitaires sur la page en cours et affiche un récapitulatif clair et structuré dans une barre latérale.
  • Outils manuels : Pour aller plus loin, l’extension propose une série d’outils interactifs qui vous permettent de vérifier visuellement certains critères souvent négligés ou difficiles à détecter automatiquement.

Utilisation

L’utilisation de Renowify est d’une simplicité déconcertante :

  1. Ouvrez la page web que vous souhaitez auditer dans votre navigateur.
  2. Cliquez sur l’icône de l’extension Renowify.
  3. L’analyse démarre automatiquement et les résultats s’affichent dans la barre latérale.
  4. Activez les outils manuels selon vos besoins pour compléter votre audit..

Liste des outils disponible

Voici les outils que vous pouvez activer à tout moment pour inspecter votre page :

  1. Textes alternatifs d’images : Vérifiez si chaque image dispose d’un attribut alt pertinent.
  2. Affichage du focus clavier : Mettez en évidence les éléments recevant le focus pour tester la navigation au clavier.
  3. Changements de langue : Identifiez les zones où une balise explicite est définie.
  4. Espacement des caractères : Modifiez l’interlettrage pour tester la lisibilité.
  5. Niveaux de titres : Visualisez la hiérarchie des titres (h1 à h6) pour vérifier leur cohérence.
  6. Attributs Autocomplete : Affichez les champs de formulaire avec leurs attributs autocomplete.
  7. Attributs des Tableau : Inspectez les balises table et leurs rôles sémantiques.
  8. Attributs "title" des liens : Listez les attributs title des liens pour évaluer leur pertinence.
  9. Contenu masqué : Afficher le contenu qui est visuellement masqué.
  10. Image de background : Vérifiez si le texte reste lisible en l'absence d'image de fond.

Pourquoi choisir Renowify ?

  • Gain de temps : Plus besoin de vérifier chaque critère manuellement, l’extension fait le gros du travail pour vous.
  • Fiabilité : Basée sur le référentiel RAWeb, elle vous guide vers une conformité solide.
  • Simplicité : Une interface claire, des résultats lisibles et une prise en main immédiate.
  • Complémentarité : Combine tests automatiques et outils manuels pour une couverture maximale.

Renowify est bien plus qu’un outil technique : c’est une démarche vers un web plus inclusif, équitable et accessible à tous. Que vous soyez développeur, intégrateur ou simplement soucieux de l’expérience utilisateur, Renowify vous aide à faire la différence.

Demander l'ajout d'un test automatique

Merci de me faire parvenir les éléments suivants :

  • Un fichier JSON d'information sur le test
                {
              "nomenclature": "01-X", // 01 correspond à la rubrique "Couleur et contraste"
              "category": "dev", // Une valeur parmi : dev (problèmes techniques), nth (nice-to-have), man (à vérifier manuellement)
              "severity": 2, // Une valeur parmi : 0 (aucun impact = Gray), 1 (impact faible = Yellow), 2 (impact moyen = Orange), 3 (impact élevé = Red)
              "references": {
                "raweb": null, // indiquer "1.1.1" pour une référence au critère 1.1 test 1 (https://accessibilite.public.lu/fr/raweb1.1/criteres.html)
                "opquast": null, // indiquer "1" pour une référence à la regle n°1 (https://checklists.opquast.com/fr/qualite-numerique/1)
                "renow": null // indiquer "001" pour une référence à la règle n°001 (https://renow.public.lu/fr/checklists-renow.html#001)
              },
              "filters": ["developer"], // valeur disponible "Developer" (Le problème ne sera remonté qu'aux développeurs), "AEM" (Le problème ne sera remonté que sur les sites AEM), "CTIE" (Le problème ne sera remonté que sur les sites du CTIE), "Live" (Le problème ne sera remonté qu'aux sites en ligne), ...
              "query": "p" // correspond au sélecteur utiliser par la méthode querySelectorAll() sur lesquels on itérera pour effectuer le test.
            },
  • Un fichier JSON avec les traductions
                "fr" : {
              "description": "Texte insuffisamment contrasté", // la description du problème qui sera affiché dans la barre latérale
              "explication": "Le script calcule le contraste entre la couleur du texte et son fond. Il vérifie si le ratio atteint les seuils requis (3:1 ou 4.5:1).", // Une explication du script utilisé pour le test
              "solution": "Le texte n’est pas assez lisible. Augmenter le contraste en ajustant la couleur du texte ou du fond." // Information complémentaire sur le problème + un exemple de solution
            }
  • Une fonction JS renvoyant le booléen true si le test détecte une erreur sur un élément de la page. Généralement les tests suivent une de ces formes :
    • Test simple, sans utilisation de la query
    • Vérifie si la query renvoi au moins un item visible (checkIfOneVisibleItemMatch)
    • Vérifie si la query renvoi au moins un item qui rempli une certaine condition (checkIfOneItemMeetsTheCondition)
    • Vérifie si les items remontés par la query remplissent une certaine condition (checkIfQueryMeetsTheCondition)
    • Vérifie si la query ne renvoi aucun item visible (checkIfNoneVisibleItemMatch)
    • Vérifie si la query ne renvoi aucun item (checkIfNoneItemMatch)
